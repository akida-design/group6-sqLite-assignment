## Database relationshios
- These are different tables that show how data is connected and relateed through shared keys.

## Relationship types
### one-to-one (1:1)
- Each record in table 'A' relates one to one with records in table 'B' and vice versa

### one to many (1:M)
- One record in table 'A' can relate to multiple records in table 'B' but each record in table 'B' can only relate with one record in table 'A'

### many-to-many (M:M)
- Multiple records in table 'A' are related to multiple records in table 'B'. This normally requires a junction table.

## Foreign key
- It is a column or set of columns in one table that references the primary key of another table.

## Real life examples
### 1:1
- One driver has one driver's licence

### 1:M
- One department has many employees but employees can only have one department.

### M:M
- Multiple doctors can treat multiple patients while multiple patients can be treated by multiple doctors.
